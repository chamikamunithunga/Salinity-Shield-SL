How it works:Satellite Data: Uses the NASA Hydrocron API to pull real-time water surface elevation ($WSE$) and slope data from the SWOT (Surface Water and Ocean Topography) satellite.The Brain: A Python-based Firebase Cloud Function that processes hydrology data and calculates risk levels based on local river thresholds.The Interface: A React + Vite dashboard with an interactive map (Leaflet) that alerts users when water levels hit "Danger" zones.
